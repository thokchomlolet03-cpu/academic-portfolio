# Maintaining the portfolio

The repository is public. Never commit transcripts, IDs, visa details, private application plans, employer records, customer PII, secrets, private certificates or restricted research data. Git history persists. Keep original private evidence off GitHub.

## Add a meaningful achievement
1. Record the actual activity and outcome; classify its status in EVIDENCE.md.
2. Link to an authorized artifact, reproducible test, public credential or publication.
3. Write a short section entry: problem, action, contribution, result, limitation.
4. Update the website only when the evidence is relevant and ready for public viewing.
5. Review scope, ownership, links and privacy. Do not count generated text as demonstrated competence.

Monthly review: remove stale claims, check links, choose the strongest three relevant accomplishments. Before applications, make a focused summary instead of expecting admissions reviewers to read every repository. Keep the website and GitHub consistent.

## Website
Static HTML lives in docs/index.html and docs/style.css; no external dependencies, analytics or forms. To publish manually using GitHub Pages: Settings → Pages → Deploy from a branch → main → /docs → Save. Check the URL and mobile layout after deployment. Publication is separate from committing the files.
