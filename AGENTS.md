# Academic portfolio — agent operating instructions

Read this file before working in the repository.

## Required startup context
1. Read [Graduate admissions status](graduate-preparation/ADMISSIONS_STATUS.md), [Evidence register](EVIDENCE.md), and [Maintenance guide](MAINTENANCE.md).
2. For academic preparation, use the [MIS Learning Hub](https://github.com/thokchomlolet03-cpu/thokchomlolet03-cpu/tree/main/learning-hub/mis) and distinguish planned study from demonstrated competence.
3. For admissions work, consult authorized private correspondence and documents only when access is available. This public status file is a coordination summary, not a replacement for private records or an authorization to disclose them.

## Mandatory update after meaningful admissions work
- Update ADMISSIONS_STATUS.md with review date, confirmed changes, evidence type, unresolved questions and next actions.
- Record only public-safe aggregate progress here. Maintain individual university records, contacts, GPA/credential details not approved for public release, private correspondence and financial details in the separate private tracker when it exists. Never commit original academic records, Gmail/Drive private links, identifiers or secrets.
- Distinguish inquiry sent, response received, eligibility confirmed, application submitted, offer received, funding confirmed, and enrollment. A reply or a published general policy does not prove individual eligibility. An automated acknowledgement is not an evaluation outcome.
- Never treat a credential report as guaranteed admission or treat a possible assistantship as awarded funding. Verify exact degree equivalency, prerequisites, funding conditions and deadlines using authoritative evidence.
- Do not invent completed courses, grades, credentials, email sends, decisions or offers. Mark claims as pending when unverified.
- Before adding public portfolio content, follow the evidence register and privacy policy; keep admissions operational records separate from reviewer-facing website.
- When an action cannot be performed, document the blocker; do not mark it complete. Preserve public-safe dated history and avoid overwriting unrelated work.

## Communication
Be direct, evidence-driven and explicit about uncertainties, limitations, and opportunity costs. Challenge assumptions rather than providing reassurance; do not confuse ambition with achievement.
